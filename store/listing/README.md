# Store listing texts

The Microsoft Store listing for the Windows version (product name **Desktop Hygge**), one file per language. Copy each
field into Partner Center (the submission's Store listings, one per language), or fill them into the CSV that
Partner Center's Store listings page exports (Import/export listings).

- `da-dk.md` Danish (the only language with the advent calendar: its texts are Danish only)
- `en-us.md` English
- `sv-se.md`, `de-de.md`, `nl-nl.md` Swedish, German, Dutch: translated by a language model, not read by a native
  speaker

Rules for the texts: only what the Windows version does; no trademarked characters (no "Rudolph"); the walkers are
named as the app shows them in that language (elves, nisser, tomtar, Wichtel, kabouters). Screenshots are made
separately (2560x1440 on a real desktop, no private content) and are not in the repo. The privacy policy is
`docs/privacy.md`.

Fields Partner Center asks for besides these: system requirements ("Windows 10 version 1809 or later, or
Windows 11"), category (Personalization), and the privacy policy URL.
